# Security policy

This is a reference implementation, not a certified security product. Only the latest main branch receives fixes. Report a vulnerability privately through GitHub's **Report a vulnerability** option if enabled. If it is unavailable, open a minimal issue asking the maintainer for a private contact; do not publish exploit details, credentials or sensitive data in that issue.

Do not run automated attacks against third-party services when testing. Use only synthetic local fixtures. Read docs/threat-model.md for the implemented controls and limits.
